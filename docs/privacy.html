Privacy

Alleyoop (Figma plugin) and Dunk (helper app). Last updated: 23 November 2026.

Short version

Nothing leaves your computer. No account, no analytics, no tracking, no server.

What the plugin reads

Only the frames you select and click to send. It exports them as PDF, SVG and PNG files, together with a small description (layer names, sizes, positions).

Where it goes

The plugin sends these files to Dunk at http://localhost:47800. This address is your own computer. Dunk accepts requests only from your machine and only from Figma.

Dunk writes the files to a temporary folder, lets Adobe Illustrator build the .ai file, and saves it to the folder you chose. Temporary files are deleted after a successful job. After a failed job the last few are kept on your computer, so you can send them with a bug report if you want.

What is stored

The plugin remembers your settings (language, text mode, save mode) in Figma's local plugin storage. Dunk keeps its settings and a log file in its application folder on your computer. Nothing is sent anywhere.

Contact

Questions: open an issue at github.com/dobotibi/alleyoop. The code is open, you can check all of this there.
